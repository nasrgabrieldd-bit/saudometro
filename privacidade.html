Política de Privacidade

Saudômetro · Última atualização: setembro de 2026

O Saudômetro é um aplicativo para casais acompanharem o humor, os encontros e os recados um do outro. Esta página explica, em linguagem simples, quais dados o app guarda, para quê, com quem são compartilhados e quais são os seus direitos, conforme a Lei Geral de Proteção de Dados (LGPD, Lei 13.709/2018).

1. Quem é o responsável

O aplicativo foi criado e é mantido por Gabriel Nascimento Santos, controlador dos dados. Para qualquer pedido sobre seus dados, escreva para nasrgabrieldd@gmail.com.

2. Quais dados o app guarda

3. Dado sensível: ciclo menstrual

Informações sobre o ciclo menstrual são dados pessoais sensíveis (dados de saúde). Por isso:

  • o recurso é opcional e só é ativado depois de você aceitar um aviso de consentimento específico;
  • por padrão, só você vê esses dados. Seu par só vê se você escolher compartilhar, e a regra é aplicada no servidor;
  • você pode desativar e apagar tudo a qualquer momento, e retirar o consentimento quando quiser;
  • as previsões são estimativas. O app não substitui orientação médica e não é método anticoncepcional.

A base legal para esse dado é o seu consentimento (LGPD, art. 11, I). Para os demais dados, a base é a execução do serviço que você pediu ao usar o app (art. 7º, V) e o legítimo interesse de segurança (art. 7º, IX).

4. Com quem os dados são compartilhados

  • Seu par: vê o que faz parte da vida a dois no app (humor, recados, encontros etc.). O ciclo só se você compartilhar.
  • Supabase: serviço de banco de dados e acesso onde os dados ficam guardados.
  • Cloudflare (Turnstile): verificação anti-robô ao criar uma conta nova.
  • GitHub Pages: hospedagem das páginas do app.
  • Serviços de notificação do seu aparelho (Apple, Google ou Mozilla), apenas se você ativar os avisos.

Não vendemos seus dados, não usamos anúncios e não compartilhamos com terceiros para publicidade. Alguns desses serviços podem armazenar dados em servidores fora do Brasil.

5. Por quanto tempo guardamos

Enquanto o casal usar o app ou até você pedir a exclusão. Ao desativar o ciclo, os dados dele são apagados. Contas sem uso podem ser removidas depois de um longo período de inatividade.

6. Seus direitos

Você pode, a qualquer momento (LGPD, art. 18): confirmar se tratamos seus dados, acessá-los, corrigi-los, pedir a eliminação, pedir a portabilidade, saber com quem compartilhamos e retirar o consentimento. No app, em Perfil, há o botão Baixar meus dados e, no ciclo, Desativar e apagar meus dados do ciclo. Para os demais pedidos, use o e-mail acima. Você também pode reclamar à Autoridade Nacional de Proteção de Dados (ANPD).

7. Segurança

Os dados trafegam com conexão segura (HTTPS). Cada casal só acessa os próprios dados, por regras de acesso aplicadas no banco. O acesso à área de administração exige senha, e ela mostra apenas totais, sem dados pessoais dos casais. Nenhum sistema é perfeito: se houver um incidente que afete você, avisaremos.

8. Crianças e adolescentes

O app é destinado a maiores de 18 anos.

9. Mudanças nesta política

Se algo mudar, atualizaremos esta página e a data no topo. Mudanças importantes serão avisadas no app.
